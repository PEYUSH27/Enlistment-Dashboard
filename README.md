# Enlistment Support Command Center

A modern React-based ERP support dashboard designed for monitoring and managing enlistment-related JIRA tickets during university admission and enrollment periods.

## 🚀 Live Demo

🔗 https://PEYUSH27.github.io/Enlistment-Dashboard/

---

# 📌 Features

- 🎫 JIRA Ticket Monitoring Dashboard
- 📊 Analytics Section with Charts
- 📈 Pending Ticket Trends Visualization
- 🥧 Employee-wise Ticket Distribution Pie Chart
- 📂 Excel / CSV Upload Support
- 🔄 Live Excel Parsing & Auto Table Update
- 🔍 Dynamic Filtering System
- 👨‍💻 Assigned Member Wise Filtering
- 🏫 University Wise Filtering (LPU-M / LPU-C)
- 🧩 Module Wise Tracking
- 📱 Responsive Modern UI
- ⚡ Fast Deployment using Vite + React
- 🌐 Hosted on GitHub Pages

# 🎯 Purpose of this Dashboard

During enlistment season, support teams receive a high volume of ERP and student-related tickets. This dashboard provides a centralized monitoring system to:

- Track ticket workload
- Monitor pending issues
- Analyze critical bottlenecks
- Improve team coordination
- Enhance visibility for management
- Speed up issue resolution
